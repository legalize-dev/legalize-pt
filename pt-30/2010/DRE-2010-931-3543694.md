# Declaração de Rectificação n.º 931/2010 — Rectifica o regulamento das provas de maiores de 23 anos

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 931/2010

Por ter saído com inexactidão o n.º 1 do artigo 7.º do regulamento n.º 285/2010, de 23 de Março, regulamento das provas especialmente adequadas destinadas a avaliar a capacidade para frequência do ensino superior dos maiores de 23 anos, nos ciclos ministrados na Universidade da Madeira, publicado no Diário da República, 2.ª série, de 23 de Março de 2010, rectifica-se o mesmo. Assim, onde se lê «A classificação de cada uma das componentes de avaliação é apresentada utilizando uma grelha de registo, de acordo com as regras e critérios de avaliação constantes no anexo a este regulamento» deve ler-se «A classificação de cada uma das componentes de avaliação é apresentada utilizando uma grelha de registo cujo modelo é fornecido pelo júri».

20 de Abril de 2010. - O Reitor, José Manuel Nunes Castanheira da Costa.
