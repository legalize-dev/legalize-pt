# Decreto Regulamentar Regional n.º 30/79/A — Acresce com várias categorias o anexo a que se refere o artigo 1.º do Decreto Regulamentar Regional n.º 26/79/A

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
