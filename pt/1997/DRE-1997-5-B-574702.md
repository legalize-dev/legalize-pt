# Declaração de Rectificação n.º 5-B/97 — De ter sido rectificado o Decreto-Lei n.º 23/97, do Ministério das Finanças, que prossegue a harmonização entre as…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se declara que o [Decreto-Lei n.º 23/97](https://diariodarepublica.pt/dr/detalhe/decreto-lei/23-1997-581222), publicado no Diário da República, 1.ª série, n.º 19, de 23 de Janeiro de 1997, cujo original se encontra arquivado nesta Secretaria-Geral, saiu com a seguinte inexactidão, que assim se rectifica:

No artigo 1.º, «Alterações ao Código de Processo Tributário», onde se lê «[Decreto-Lei n.º 194/91](https://diariodarepublica.pt/dr/detalhe/decreto-lei/194-1991-631203),» deve ler-se «[Decreto-Lei n.º 154/91](https://diariodarepublica.pt/dr/detalhe/decreto-lei/154-1991-594675),».

Secretaria-Geral da Presidência do Conselho de Ministros, 25 de Fevereiro de 1997. - O Secretário-Geral, Alexandre Figueiredo.
