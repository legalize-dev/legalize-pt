# Declaração de Retificação n.º 1071/2024/2 — Retifica a lista nominativa do pessoal docente que obteve provimento no quadro do Agrupamento de Escolas da Maia, com…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
