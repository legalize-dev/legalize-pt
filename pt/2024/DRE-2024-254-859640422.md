# Declaração de Retificação n.º 254/2024/2 — Retifica o Aviso (extrato) n.º 4548/2024, de 29 de fevereiro

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Onde se lê:

"Paula Cristina Oliveira Santos"

deve ler-se:

"Paula Sofia Oliveira Santos"

18 de março de 2024. - A Vice-Presidente do Conselho Diretivo, Catarina Marcelino.
