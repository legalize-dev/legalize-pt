# Declaração de Retificação n.º 912/2024/2 — Retifica o Despacho n.º 6740/2024, publicado no Diário da República, 2.ª série, n.º 115, de 17 de junho de 2024

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Nos termos do disposto no n.º 2 do artigo 11.º do Regulamento de Publicação de Atos no Diário da República, aprovado pelo [Despacho Normativo n.º 16/2022](https://diariodarepublica.pt/dr/detalhe/despacho-normativo/16-2022-205457496), de 30 de dezembro, declara-se que o Despacho n.º 6740/2024, publicado no Diário da República, 2.ª série, n.º 115, de 17 de junho de 2024, saiu com a seguinte inexatidão, que, mediante declaração da entidade emitente, se retifica:

1 - No n.º 1.1 da tabela ii do n.º 1 do artigo 2.º do anexo, onde se lê:

| "Procedimentos | Taxas (euros) |
| --- | --- |
| 1 - [...] |  |
| 1.1 - Vistoria técnica | 173,00 |
| 1.2 - [...] | [...] |
| 2 - [...] | [...]" |

deve ler-se:

| "Procedimentos | Taxas (euros) |
| --- | --- |
| 1 - [...] |  |
| 1.1 - Vistoria técnica | 173,10 |
| 1.2 - [...] | [...] |
| 2 - [...] | [...]" |

2 - No n.º 1.1 da tabela ii do n.º 1 do artigo 3.º do anexo, onde se lê:

| "Procedimentos | Taxas (euros) |
| --- | --- |
| 1 - [...] |  |
| 1.1 - Vistoria técnica | 173,00 |
| 1.2 - [...] | [...] |
| 2 - [...] | [...]" |

deve ler-se:

| "Procedimentos | Taxas (euros) |
| --- | --- |
| 1 - [...] |  |
| 1.1 - Vistoria técnica | 173,10 |
| 1.2 - [...] | [...] |
| 2 - [...] | [...]" |

24 de outubro de 2024. - A Diretora-Geral, Susana Isabel Ferreira Guedes Pombo.
