# Declaração de Retificação n.º 976/2024/2 — Retifica o Despacho n.º 5558/2024, de 7 de maio, publicado no Diário da República, 2.ª série, n.º 98, de 21 de maio de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
