# Declaração de Retificação n.º 286/2024/2 — Retifica o Edital n.º 1539/2023, publicado no Diário da República, 2.ª série, n.º 160, de 18 de agosto de 2023

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexatidão o [Edital n.º 1539/2023](https://diariodarepublica.pt/dr/detalhe/edital/1539-2023-220059163), publicado no Diário da República, 2.ª série, n.º 160, de 18 de agosto de 2023, referente ao concurso para promoção para professor associado para a área disciplinar de Física, retifica-se que onde se lê:

"7.6 - A mensuração da ponderação associada aos parâmetros de avaliação é apresentada na tabela seguinte:

| Critérios | Ponderação | Parâmetros | Ponderação |  |
| --- | --- | --- | --- | --- |
| Desempenho Científico (DC) | 55 % | DC1 - Produção científica (PC) | 80 % |  |
| Desempenho Científico (DC) | 55 % | DC2 - Participação em projetos científicos (PPC) | 10 % |  |
| Desempenho Científico (DC) | 55 % | DC3 - Reconhecimento pela Comunidade Científica (RCC) | 10 % |  |
| Subtotal A | Subtotal A | Subtotal A | 100 % |  |
| Desempenho Pedagógico (DP) | 30 % | DP1 - Atividade de ensino (AE) | 30 % |  |
| Desempenho Pedagógico (DP) | 30 % | DP2 - Produção de material pedagógico (PMP) | 30 % |  |
| Desempenho Pedagógico (DP) | 30 % | DP3 - Inovação e valorização para a atividade de ensino (IVAE) | 10 % |  |
| Desempenho Pedagógico (DP) | 30 % | DP5 - Participação em projetos pedagógicos noutras instituições (PPP) | 05 % |  |
| Desempenho Pedagógico (DP) | 30 % | DP6 - Relatório sobre os conteúdos, métodos de ensino e bibliografia (REL) | 15 % |  |
| Subtotal B | Subtotal B | Subtotal B | 100 % |  |
| Outras Atividades Relevantes (OAR) | 15 % | OAR1 - Gestão Universitária (GU) | 20 % |  |
| Outras Atividades Relevantes (OAR) | 15 % | OAR2 - Transferência de Conhecimento e Tecnologia (TCT) | 80 % |  |
| Subtotal C | Subtotal C | Subtotal C | 100 % |  |
| Total | 100 % | Total ponderado[DC × 0,55) + (DP × 0,30) + (OAR × 0,15)] | 100 % | " |

deve ler-se:
