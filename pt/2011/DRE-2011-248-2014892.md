# Declaração de Rectificação n.º 248/2011 — Rectifica a publicação no Diário da República, 2.ª série, n.º 250, de 28 de Dezembro de 2010, de p. 62802 a p. 62809…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
