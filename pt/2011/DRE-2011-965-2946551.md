# Declaração de Rectificação n.º 965/2011 — Rectifica o aviso n.º 2769/2011, publicado no Diário da República, 2.ª série, n.º 18, de 26 de Janeiro de 2011…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 965/2011
