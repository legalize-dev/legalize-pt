# Declaração de Rectificação n.º 59/2011 — Rectifica o aviso n.º 26 895/2010, de 22 de Dezembro, do Agrupamento de Escolas de Cantanhede

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 59/2011

Rectifica-se o aviso n.º 26 895/2010, de 22 de Dezembro. Assim, onde se lê «Palmira Barreto Manata dos Santos» deve ler-se «Palmira Barreto Luz Carvalho».

30 de Dezembro de 2010. - A Directora, Fátima Maria Vaz Gomes de Jesus Simões.
