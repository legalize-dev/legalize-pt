# Declaração de Rectificação n.º 1501/2011 — Rectifica o procedimento concursal comum para a categoria de assistente operacional aberto pelo aviso n.º 16747/2011

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1501/2011

Rectificação do procedimento concursal comum para a categoria de assistente operacional, aberto pelo aviso n.º 16 747/2011, publicado no Diário da República, 2.ª série, n.º 165, de 29 de Agosto de 2011.

O Agrupamento de Escolas Fernão do Pó torna público que, em virtude de ter saído com inexactidão o aviso supra-identificado, rectifica-se que, no n.º 4, relativamente à remuneração ilíquida, onde se lê «3,00(euro)/hora» deve ler-se «(euro) 3,20/hora».

28 de Setembro de 2011. - O Director, Emanuel José dos Anjos Vilaça.
