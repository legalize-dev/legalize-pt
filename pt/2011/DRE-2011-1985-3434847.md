# Declaração de Rectificação n.º 1985/2011 — Rectifica o aviso n.º 20689/2011 publicado no Diário da República, 2.ª série, n.º 200, de 18 de Outubro de 2011

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1985/2011

Por ter sido publicado com inexactidão no Diário da República, 2.ª série, n.º 200, de 18 de Outubro de 2011, o aviso n.º 20689/2011, rectifica-se que onde se lê:

«Posto A: CF = (PC x 0,30) + (AP x 0,25) + (AC x 0,45)»

«Posto B: CF = (PC x 0,30) + (AP x 0,25) + (EPS x 0,45)»

deve ler-se:

«Posto A: CF = (PC x 0,45) + (AP x 0,25) + (AC x 0,30)»

«Posto B: CF = (PC x 0,45) + (AP x 0,25) + (EPS x 0,30)»

25 de Novembro de 2011. - O Presidente da Câmara, João Fernando Brum de Azevedo e Castro.
