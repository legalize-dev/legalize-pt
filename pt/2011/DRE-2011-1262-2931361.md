# Declaração de Rectificação n.º 1262/2011 — Rectifica o aviso n.º 27816/2010, publicado no Diário da República, 2.ª série, n.º 253, de 31 de Dezembro de 2010

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1262/2011

Rectificação do aviso n.º 27816/2010, publicado no Diário da República, 2.ª série, n.º 253, de 31 de Dezembro de 2010

Faz-se público que, no segundo parágrafo do n.º 8.1 do aviso, «Bibliografia tema 2», onde se lê «Recomendações para a gestão de documentos de arquivo» deve ler-se «Recomendações para a gestão de documentos de arquivo electrónicos» e onde se lê «Orientações para a descrição arquivística, 2.º vol.» deve ler-se «Orientações para a descrição arquivística, 2.ª versão».

1 de Agosto de 2011. - Pelo Presidente, a Directora Municipal de Administração e Desenvolvimento Organizacional, Paula Magalhães Saraiva.
