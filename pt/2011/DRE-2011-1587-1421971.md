# Declaração de Rectificação n.º 1587/2011 — Rectifica o aviso de renovação de comissão de serviço Maria Joaquina Soares

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1587/2011

Para os devidos efeitos se torna público a rectificação do aviso n.º 2338/2011 publicado no Diário da República, 2.ª série, n.º 15, de 21 de Janeiro de 2011. Assim, onde se lê «com efeitos a partir de 31 de Janeiro de 2009» deverá ler-se «a partir de 31 de Janeiro de 2010».

7 de Outubro de 2011. - O Presidente, Joaquim Martins Gonçalves.
