# Declaração de Rectificação n.º 1364/2011 — Rectifica o despacho n.º 4690/2011, publicado no Diário da República, 2.ª série, n.º 53, de 16 de Março de 2011

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
