# Declaração de Rectificação n.º 34/2011 — Rectifica o Decreto-Lei n.º 111/2011, de 28 de Novembro, do Ministério da Economia e do Emprego, que sujeita os lanços…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
