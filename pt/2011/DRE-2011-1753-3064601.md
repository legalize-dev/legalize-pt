# Declaração de Rectificação n.º 1753/2011 — Elimina o n.º 4.1 dos requisitos de admissão do aviso n.º 21752/2011, publicado no Diário da República, 2.ª série, n.º…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1753/2011

No aviso n.º 21752/2011, publicado no Diário da República, 2.ª série, n.º 210, de 2 de Novembro de 2011, deve considerar-se sem efeito o n.º 4.1 dos requisitos de admissão.

3 de Novembro de 2011. - O Presidente, Graciano Manuel Oliveira Cerqueira.
