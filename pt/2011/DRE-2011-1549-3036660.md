# Declaração de Rectificação n.º 1549/2011 — Rectifica o despacho n.º 2825/2011, de aprovação de modelo n.º 245.04.11.3.01 de António Moutinho, publicado no Diário…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1549/2011

No Diário da República, 2.ª série, n.º 28, de 9 de Fevereiro de 2011, foi publicado com inexactidão, o despacho n.º 2825/2011, de aprovação de modelo n.º 245.04.11.3.01.

Assim, onde se lê «Gama de funcionamento: 0 até 100 bar» deve ler-se «Gama de funcionamento: 0 até 1000 bar»

4 de Agosto de 2011. - O Presidente do Conselho Directivo, J. Marques dos Santos.
