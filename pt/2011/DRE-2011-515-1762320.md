# Declaração de Rectificação n.º 515/2011 — Rectifica o aviso n.º 4731/2011, publicado no Diário da República, 2.ª série, n.º 33, de 16 de Fevereiro de 2011, de…

> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 515/2011

Por ter sido publicado com inexactidão, rectifica-se pelo presente o aviso n.º 4731/2011, publicado no Diário da República, 2.ª série, n.º 33, de 16 de Fevereiro de 2011. Assim, a presente lista refere-se aos docentes contratados para o ano lectivo de 2010-2011.

28 de Fevereiro de 2011. - O Presidente, António Agnelo Figueiredo.
