# Declaração de Rectificação n.º 1228/2011 — Rectifica o aviso n.º 14939/2011

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1228/2011

Rectificação do aviso n.º 14939/2011, publicado no Diário da República, 2.ª série, n.º 143, de 27 de Julho de 2011

1 - No n.º 6.1, onde se lê «AC = HAB x 40 % + FP x 10 % + EP x 40 % x AD x 10 %» deve ler-se «AC = HAB x 40 % + FP x 10 % + EP x 40 % + AD x 10 %».

2 - No n.º 6.2, onde se lê «Competências consideras essenciais» deve ler-se «Competências consideradas essenciais».

3 - No n.º 6.3, onde se lê «na escala de o a 20 valores» deve ler-se «na escala de 0 a 20 valores».

28 de Julho de 2011. - O Director, Joaquim António Rodrigues de Mira.
