# Declaração de Rectificação n.º 13-B/96 — De ter sido rectificado o Decreto n.º 21/96, do Ministério dos Negócios Estrangeiros, que aprova, para assinatura, a…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se declara que o [Decreto n.º 21/96](https://diariodarepublica.pt/dr/detalhe/decreto/21-1996-417039), publicado no Diário da República, 1.ª série, n.º 169, de 23 de Julho de 1996, cujo original se encontra arquivado nesta Secretaria-Geral, saiu com as seguintes inexactidões, que assim se rectificam:

No sumário, onde se lê «Aprova, para assinatura,» deve ler-se «Aprova, para ratificação,».

No artigo 1.º, onde se lê «São aprovados, para assinatura,» deve ler-se «São aprovados, para ratificação,».

Secretaria-Geral da Presidência do Conselho de Ministros, 27 de Agosto de 1996. - O Secretário-Geral, Alexandre Figueiredo.
