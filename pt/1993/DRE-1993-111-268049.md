# Despacho Normativo n.º 111/93 — Fixa os valores definitivos para as indemnizações respeitantes a várias sociedades

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

O [Decreto-Lei n.º 332/91](https://diariodarepublica.pt/dr/detalhe/decreto-lei/332-1991-304536), de 6 de Setembro, redefine em alguns aspectos o cálculo das indemnizações. À medida que se vão apurando os novos valores definitivos, os mesmos serão publicados de modo a permitir a disponibilização dos títulos do empréstimo interno amortizável denominado «OT 1977 - Nacionalizações e expropriações».
