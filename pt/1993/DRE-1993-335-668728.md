# Despacho Normativo n.º 335/93 — Fixa os valores definitivos para as indemnizações respeitantes a várias sociedades

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

À medida que vão sendo recalculados os valores definitivos das empresas nacionalizadas, à luz dos critérios constantes do [Decreto-Lei n.º 332/91](https://diariodarepublica.pt/dr/detalhe/decreto-lei/332-1991-304536), de 6 de Setembro, tem-se vindo a promover a respectiva publicação.
