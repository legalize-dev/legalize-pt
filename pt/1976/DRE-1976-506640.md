# Resolução do Conselho de Ministros — Nomeia diversas individualidades para os conselhos de gestão das instituições de crédito nacionalizadas

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

O Conselho de Ministros, reunido em 27 de Janeiro de 1976, resolveu:
