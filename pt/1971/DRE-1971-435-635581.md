# Portaria n.º 435/71 — Manda abonar à Embaixada de Portugal no Luxemburgo, com efeitos a partir de 1 de Julho último, uma quantia mensal, a…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

de 16 de Agosto
