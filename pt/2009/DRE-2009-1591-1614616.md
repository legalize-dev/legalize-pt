# Declaração de Rectificação n.º 1591/2009 — Rectificação do despacho n.º 7897/2009, de 19 de Março

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Rectifica-se o [Despacho n.º 7897/2009](https://diariodarepublica.pt/dr/detalhe/despacho/7897-2009-2307825), publicado no DR, II, n.º 55 de 19-03-2009, onde se lê «nível remuneratório 27, subnível 21», deve ler-se «escalão 1, índice 135».

23 de Junho de 2009. - O Vogal do Conselho Directivo, António José da Silva Pimenta Marinho.
