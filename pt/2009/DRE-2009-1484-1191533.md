# Declaração de Rectificação n.º 1484/2009 — Rectificação da deliberação n.º 1126/2009, de 16 de Abril

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1484/2009

Por ter saído com inexactidão a deliberação n.º 1126/2009 (2.ª série) publicada no D.R. n.º 74 de 16.04.2009, referente ao Programa de Doutoramento em Turismo, rectifica-se que:

- no anexo "Formulário", quadro n.º 1 - Observações, onde se lê "... sete seminários temáticos nessa área (72 ECTS) ... Tese (28 ECTS) ..." deve ler-se "... sete seminários temáticos nessa área (7 x 2 ECTS) ... Tese (2 x 8 ECTS) ...";

- no anexo "Formulário", quadro n.º 2 - Observações, onde se lê "... três seminários temáticos nessa área (32 ECTS) ..." deve ler-se "... três seminários temáticos nessa área (3 x 2 ECTS) ...";

- no anexo "Formulário", quadro n.º 3 - Observações, onde se lê "... três seminários temáticos nessa área (32 ECTS) ..." deve ler-se "... três seminários temáticos nessa área (3 x 2 ECTS) ...";
