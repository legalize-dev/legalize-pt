# Declaração de Rectificação n.º 261/2009 — Rectificação do aviso 25089/2008

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 261/2009

Por ter saído com inexactidão o aviso n.º 25089/2008, publicado no Diário da República, n.º 201, 2.ª série, de 16 de Outubro de 2008, rectifica-se que no n.º 4.5 onde se lê "...Trabalhos de interesse para o serviço (normas, protocolos, instrumentos de registo) ..." deve ler-se "... Trabalhos de interesse para o serviço (normas, protocolos, instrumentos de registo) - 0,25 cada até 1 ponto ..." (Isento de fiscalização prévia do Tribunal de Contas.)

23 de Janeiro de 2009. - A Presidente do Conselho de Administração, Adelaide Belo.
