# Declaração de Rectificação n.º 1974/2009 — Rectifica o despacho n.º 16316/2009, de 16 de Julho

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexactidão o [Despacho n.º 16316/2009](https://diariodarepublica.pt/dr/detalhe/despacho/16316-2009-865838), publicado no D.R. n.º 136, 2.ª série, de 16 de Julho de 2009, rectifica-se, onde se lê" director desta Escola" deve ler-se "director deste Agrupamento".

4 de Agosto de 2009. - O Director, Alberto Machado.
