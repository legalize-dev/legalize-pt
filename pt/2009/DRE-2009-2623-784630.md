# Declaração de Rectificação n.º 2623/2009 — Declaração de rectificação do despacho n.º 28 367/2008, de 5 de Novembro

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2623/2009

No despacho n.º 28 367/2008, publicado no Diário da República, 2.ª série, n.º 215, de 5 de Novembro de 2008, rectifica-se que onde se lê «Jorge Manuel Duarte de Sousa» deve ler-se «Jorge Manuel Duarte de Sousa Ribeiro».

16 de Outubro de 2009. - A Directora, Maria Catarina Lopes Paiva.
