# Declaração de Rectificação n.º 1843/2009 — Rectifica o despacho n.º 17 348/2009, publicado no Diário da República, 2.ª série n.º 144, de 28 de Julho de 2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexactidão no Diário da República, 2.ª série n.º 144 de 28 de Julho de 2009 o [Despacho n.º 17348/2009](https://diariodarepublica.pt/dr/detalhe/despacho/17348-2009-922351) relativo a nomeação para o cargo de Adjunto, rectifica-se onde se lê" Agrupamento Básicas Agrupamento""deve ler-se Agrupamento.
