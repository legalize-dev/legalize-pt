# Declaração de Rectificação n.º 874/2009 — Rectifica a lista de classificação final do concurso interno geral de acesso para preenchimento de cinco lugares de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
