# Declaração de Rectificação n.º 1871/2009 — Rectificação de nome em despacho de nomeação

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se rectifica que no [Despacho (extracto) n.º 17712/2009](https://diariodarepublica.pt/dr/detalhe/despacho-extracto/17712-2009-1433892), publicado no Diário da República, 2.ª série, n.º 147, de 31 de Julho de 2009, na página 30724 onde se lê "...Doutor Nycolay Vsevolodovich Lukoyanov..." deve ler-se "...Doutor Nicolay Vsevolodovich Lukoyanov ..."

31 de Julho de 2009. - O Reitor, José C. D. Marques dos Santos.
