> a separate file in this repository and a commit in this file's history.**

Onde se lê:

«... para o cargo de Director de Serviços Técnicos ...»

«... para o cargo de Director do Laboratório de Segurança Alimentar...»

16 de Janeiro de 2009. - O Inspector-Geral, António Nunes.
