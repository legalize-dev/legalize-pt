# Declaração de Rectificação n.º 2671/2009 — Agrupamento Vertical de Escolas de Pedras Salgadas - rectifica o aviso n.º 18 839/2009, de 23 de Outubro

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2671/2009

No aviso n.º 18 839/2009, publicado no Diário da República, 2.ª série, n.º 206, de 23 de Outubro de 2009, rectifica-se que onde se lê «15 de Setembro de 2009. - O Director» deve ler-se «15 de Outubro de 2009. - O Director».

23 de Outubro de 2009. - O Director, Nelson de Souza Gonçalves Rodrigues.
