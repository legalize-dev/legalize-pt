# Declaração de Rectificação n.º 1152/2009 — Rectifica o aviso n.º 7027/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Foi publicado com inexactidão no Diário da República, 2.ª série, n.º 64, de 1 de Abril de 2009, o ponto 8.3 do [Aviso n.º 7027/2009](https://diariodarepublica.pt/dr/detalhe/aviso/7027-2009-1142542).

Assim, onde se lê:

AC = (HA + FP + (EP x 2))/1.4

deve ler-se:

AC = (HA + FP + (EP x 2))/4

22 de Abril de 2009. - A Presidente do Conselho Executivo, Adília Maria Rosa Fonseca Ferreira da Cruz.
