# Declaração de Rectificação n.º 2702/2009 — Rectifica o despacho (extracto) n.º 23 553/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2702/2009

Para os devidos efeitos se rectifica que na publicação inserta no Diário da República, 2.ª série, n.º 208, de 27 de Outubro de 2009, despacho (extracto) n.º 23 553/2009, onde se lê «Por despacho de 22 de Julho» deve ler-se «Por despacho de 19 de Outubro».

28 de Outubro de 2009. - A Directora de Serviços, Maria Fernanda Melo.
