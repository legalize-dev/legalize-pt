# Declaração de Rectificação n.º 1589/2009 — Rectificação do despacho n.º 7896/2009, de 19 de Março

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Rectifica-se o [Despacho n.º 7896/2009](https://diariodarepublica.pt/dr/detalhe/despacho/7896-2009-2307824), publicado no Diário da República, 2.ª série, n.º 55 de 19-03-2009, onde se lê «nível remuneratório 18, subnível 60» deve ler-se «escalão 1, índice 153».

23 de Junho de 2009. - O Vogal do Conselho Directivo, António José da Silva Pimenta Marinho.
