# Declaração de Rectificação n.º 1023/2009 — Rectifica o concurso interno de acesso para técnico superior jurista principal

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1023/2009

Concurso interno de acesso geral para provimento de um lugar para técnico superior jurista principal

Para os devidos efeitos rectifica-se o aviso n.º 3063/09, publicado no Diário da República n.º 24 de 04/02/08, que de imediato se enuncia:

Assim onde se lê:

"...por urgente conveniência de serviço a partir de 31 de Dezembro de 2008."

Dever-se-á ler:

"...com efeitos a partir de 31 de Dezembro de 2008."

20 de Março de 2009. - Por delegação de competências do Presidente da Câmara, o Vereador do Departamento de Recursos Humanos, António Pereira.
