# Declaração de Rectificação n.º 1778/2009 — Rectifica o aviso n.º 9976/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter sido publicado com inexactidão no Diário da República, n.º 99, 2.ª série, de 22 de Maio de 2009, p. 20679, o [Aviso n.º 9976/2009](https://diariodarepublica.pt/dr/detalhe/aviso/9976-2009-2090115), referente ao procedimento concursal comum para um posto de trabalho de Técnico Superior, rectifica-se:

Onde se lê "CF = 0,55 (AC) + 0,45 (EPS)" deve ler -se "CF = 0,70 (AC) + 0,30 (EPS)"

15 de Julho de 2009. - O Director Regional, Luís Marques.
