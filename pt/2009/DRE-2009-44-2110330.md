# Declaração de Rectificação n.º 44/2009 — Rectificação do despacho n.º 32062/2008

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 44/2009

Por ter sido publicado com inexactidão no Diário da República, 2.ª Série, n.º 242, de 16-12-2008, página 50303, Despacho n.º 32062/2008, rectifica-se que onde se lê "da Estrutura Central" deve ler-se "da Faculdade de Letras".

(Não carece de verificação prévia do Tribunal de Contas)

22 de Dezembro de 2008. - O Vice-Reitor, António Gomes Martins.
