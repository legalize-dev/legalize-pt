# Declaração de Rectificação n.º 1777/2009 — Rectifica o despacho n.º 14 934/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexactidão no Diário da República, 2.ª série n.º 126 de 2 de Julho de 2008 o [Despacho n.º 14934/2009](https://diariodarepublica.pt/dr/detalhe/despacho/14934-2009-1450152), relativo a nomeação para o cargo de Adjunta, rectifica-se onde se lê "Ana Paula das Dores Mestre Azedo" deve ler-se Ana Paula das Dores Mestre Azevedo.

17 de Julho de 2009. - O Director, Joaquim Inácio Godinho Cabecinha.
