# Declaração de Rectificação n.º 1313/2009 — Rectificação do despacho (extracto) n.º 10414/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter sido publicado com inexactidão, solicita-se a rectificação do [Despacho (extracto) n.º 10414/2009](https://diariodarepublica.pt/dr/detalhe/despacho-extracto/10414-2009-3047975), publicado no Diário da República, 2.ª Série, n.º 77, de 21/04/2009, pág. 16083, Onde se lê «Doutora Andrea Rodriguez Iglesias» deve ler-se «Licenciada Andrea Rodriguez Iglesias» mantendo-se o restante inalterável.

14 de Maio de 2009. - O Director, Jorge Fernandes Alves.
