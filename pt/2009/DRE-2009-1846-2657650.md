# Declaração de Rectificação n.º 1846/2009 — Rectifica o nome da subdirectora

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexactidão no Diário da República n.º 144, 2.ª Série, de 28 de Julho de 2009, o [Despacho n.º 17353/2009](https://diariodarepublica.pt/dr/detalhe/despacho/17353-2009-922358), relativo à nomeação para o cargo de Subdirectora, rectifica-se onde se lê "Dora Isabel Lúcio Morgado Pereira" deve ler-se "Dora Isabel Lúcio Morgado".

28 de Julho de 2009. - O Director, César Gabriel Barreira.
