# Declaração de Rectificação n.º 1836/2009 — Rectifica o aviso n.º 13 005/2009, publicado no Diário da República, 2.ª série, n.º 141, de 23 de Julho de 2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se declara que o [Aviso n.º 13005/2009](https://diariodarepublica.pt/dr/detalhe/aviso/13005-2009-2429118), publicado no Diário de República, 2.ª Série, n.º 141, de 23 de Julho de 2009, cujo original se encontra arquivado nesta Direcção-Geral, saiu com as seguintes inexactidões, que assim se rectificam:

Onde se lê «Sumário: Procedimento concursal comum de recrutamento para preenchimento de 2 postos de trabalho na carreira Assistente Técnico» deve ler-se «Sumário: Procedimento concursal comum de recrutamento para preenchimento de 1 posto de trabalho na carreira Técnico Superior»;

Onde se lê «17 - [...] Procedimento concursal comum de recrutamento para preenchimento de 2 postos de trabalho na carreira de Técnico Superior.» deve ler-se 17 - [...] Procedimento concursal comum de recrutamento para preenchimento de 1 posto de trabalho na carreira de Técnico Superior».

23 de Julho de 2009. - A Directora-Geral, Rita Brito.
