# Declaração de Rectificação n.º 2720/2009 — Declaração de rectificação do despacho n.º 21159/2009, de concessão de estatuto de igualdade de direitos e deveres

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
