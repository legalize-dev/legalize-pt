# Declaração de Rectificação n.º 780/2009 — Rectifica o despacho n.º 4198/2009, inserido no Diário da República, 2.ª serie, n.º 23, de 3 de Fevereiro de 2009, a p…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se rectifica o [Despacho n.º 4198/2009](https://diariodarepublica.pt/dr/detalhe/despacho/4198-2009-3184109), inserido no Diário da República, 2.ª série, n.º 23 de 3 de Fevereiro de 2009, a página 4900, coluna 2.ª, pelo que onde se lê "Eberhard Axel Wilhem" deve ler-se "Eberhard Axel Wilhelm."

17 de Fevereiro de 2009. - O Director, Francisco Guerra Tavares.
