# Declaração de Rectificação n.º 943/2009 — Rectifica o despacho n.º 25404/2008

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Universidade de Trás-os-Montes e Alto Douro

Escola Superior de Enfermagem de Vila Real

deve ler-se:

Universidade de Trás-os-Montes e Alto Douro

[([ver documento original](https://files.diariodarepublica.pt/2s/2009/03/063000000/1223812238.pdf))](https://files.diariodarepublica.pt/2s/2009/03/063000000/1223812238.pdf)
