# Declaração de Rectificação n.º 1478/2009 — Rectificação do despacho n.º 13266/2009

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos, declara-se que o [Despacho n.º 13266/2009](https://diariodarepublica.pt/dr/detalhe/despacho/13266-2009-3000976), publicado no Diário da República, 2.ª série, n.º 109, de 05 de Junho de 2009, saiu com a seguinte inexactidão, que agora se rectifica:

Assim onde se lê:

"Agrupamento de Escolas de Arouca";

"[Despacho n.º 13266/2009](https://diariodarepublica.pt/dr/detalhe/despacho/13266-2009-3000976)".

deve ler-se:

"Escola Secundária de Arouca";

"Despacho (extracto) n.º 13266/2009".

5 de Junho de 2009. - O Presidente do Conselho Geral Transitório, Carlos Alberto Gomes Ferreira.
