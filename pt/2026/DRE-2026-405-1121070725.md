# Declaração de Retificação n.º 405/2026/2 — Retifica o Despacho (extrato) n.º 12266/2025, publicado no Diário da República, 2.ª série, n.º 202, de 20 de outubro de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
