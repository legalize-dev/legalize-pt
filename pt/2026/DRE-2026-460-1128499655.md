# Declaração de Retificação n.º 460/2026/2 — Retificação do Aviso n.º 11328/2026/2, publicado no Diário da República, 2.ª série, n.º 94, de 15 de maio de 2026

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Onde se lê:

«5 - Formalização das candidaturas: A candidatura deve ser formalizada de forma eletrónica, mediante o envio da candidatura para a ULSVDL, até às 23.59 horas do último dia do período de candidatura para o seguinte endereço eletrónico: sec.presidente@ulsvdl.min-saude.pt.

5.1 - O formulário deverá ser acompanhado dos seguintes documentos:»

«5 - Formalização das candidaturas: A candidatura deve ser formalizada de forma eletrónica, mediante o envio da candidatura para a ULSVDL, até às 23.59 horas do último dia do período de candidatura para o seguinte endereço eletrónico: sec.presidente@ulsvdl.min-saude.pt.
