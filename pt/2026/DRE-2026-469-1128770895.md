# Declaração de Retificação n.º 469/2026/2 — Retifica o Despacho (extrato) n.º 12069/2025, publicado no Diário da República, 2.ª série, n.º 198, de 14 de outubro de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
