# Declaração de Retificação n.º 196/2026/2 — Retifica o Aviso (extrato) n.º 3654/2026/2, publicado no Diário da República, 2.ª série, n.º 35, de 19 de fevereiro de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter sido publicado com inexatidão o [Aviso (extrato) n.º 3654/2026/2](https://diariodarepublica.pt/dr/detalhe/aviso-extrato/3654-2026-1051704897), no Diário da República, 2.ª série, n.º 35, de 19 de fevereiro de 2026, retifica-se que:

Onde se lê:

«Área Hospitalar

| Especialidade | N.º Vagas |  |
| --- | --- | --- |
| ... |  |  |
| Pneumologia | 1 |  |
| ... |  | » |

deve ler-se:

«Área Hospitalar

| Especialidade | N.º Vagas |  |
| --- | --- | --- |
| ... |  |  |
| Ginecologia/Obstetrícia | 1 |  |
| ... |  | » |

Consideram-se válidas as candidaturas entradas para as diversas áreas, exceto a área de pneumologia, dado não haver vaga para esta área a concurso, mas sim na área de ginecologia/obstetrícia.

O prazo para apresentação das candidaturas é de cinco dias úteis, contados a partir da data da publicação da presente Declaração de Retificação no Diário da República, para a área de ginecologia/obstetrícia.

19 de fevereiro de 2026. - O Presidente do Conselho de Administração, José Miguel da Costa Lopes.
