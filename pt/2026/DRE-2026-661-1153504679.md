# Declaração de Retificação n.º 661/2026/2 — Retifica o Aviso (extrato) n.º 12167/2026/2, de 22 de maio, referente à celebração de contrato de trabalho em funções…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
