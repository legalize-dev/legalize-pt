# Declaração de Retificação n.º 658/2026/2 — Retifica o Despacho n.º 8772/2026, de 10 de julho, referente à organização dos Serviços do Município de São Pedro do…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
