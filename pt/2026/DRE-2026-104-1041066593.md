# Declaração de Retificação n.º 104/2026/2 — Retifica o Despacho (extrato) n.º 10982/2025, publicado no Diário da República, 2.ª série, n.º 180, de 18 de setembro…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
