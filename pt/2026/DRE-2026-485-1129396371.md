# Declaração de Retificação n.º 485/2026/2 — Retificação dos Avisos (extratos), de homologação do período experimental, n.os 68/2026/2, 30682/2025/2, 30681/2025/2…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
