# Portaria n.º 18611 — Manda abonar ao Consulado de Portugal em Dar-es-Salaam, com efeitos a partir de 1 de Maio do corrente ano, várias…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

... Libras

Escriturário ... 41-05-00

Dactilógrafo ... 41-05-00

Empregado ... 10-00-00

Guarda ... 7-10-00

... 100-00-00

Ministério dos Negócios Estrangeiros, 22 de Julho de 1961. - O Ministro dos Negócios Estrangeiros, Alberto Marciano Gorjão Franco Nogueira.
