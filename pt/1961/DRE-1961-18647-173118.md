# Portaria n.º 18647 — Manda abonar ao Consulado de Portugal em Singapura, com efeito a partir de 1 do corrente mês, várias quantias mensais a…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Empregado ... 60-00-00

Contínuo ... 15-00-00

... 175-00-00

Ministério dos Negócios Estrangeiros, 9 de Agosto de 1961. - O Ministro dos Negócios Estrangeiros, Alberto Marciano Gorjão Franco Nogueira.
