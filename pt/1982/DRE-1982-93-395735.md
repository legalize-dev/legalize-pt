# Despacho Normativo n.º 93/82 — Fixa os preços máximos dos serviços prestados pelos estabelecimentos termais

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Ao abrigo do n.º 2 da [Portaria n.º 659/77](https://diariodarepublica.pt/dr/detalhe/portaria/659-1977-277276), de 25 de Outubro, determina-se o seguinte:
