# Portaria n.º 410/78 — Fixa, para o ano de 1978, as dotações de artigos de uniforme para os instruendos dos cursos de oficiais da reserva…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

de 27 de Julho

Considerando o disposto no artigo único do [Decreto-Lei n.º 45531](https://diariodarepublica.pt/dr/detalhe/decreto-lei/45531-1964-469231), de 16 de Janeiro de 1964, e no artigo 1.º do [Decreto-Lei n.º 111/74](https://diariodarepublica.pt/dr/detalhe/decreto-lei/111-1974-412432), de 16 de Março:
