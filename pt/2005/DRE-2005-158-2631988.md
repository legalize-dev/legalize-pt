# Portaria n.º 158/2005 (2.ª série)

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

ASP SP Psic. Militar RC (06405894) Cáudia Alexandra Lopes Simões.

ASP SP Lic. História RC (01163698) Célia Pereira da Costa.

ASP SP Psic. Militar RC (03604496) Filipa Delgado dos Reis Valério.

ASP SP Psic. Militar RC (05689996) Hugo Filipe dos Santos Ramos.

ASP SP Lic. Direito RC (15746094) Maria Otília Gregório Rosa.

ASP SP Sociologia RC (01474496) Rute Miriam Soares dos Santos.

ASP SP Lic. Direito RC (08862795) Susana Alexandra Queroz Pinto Canizes.
