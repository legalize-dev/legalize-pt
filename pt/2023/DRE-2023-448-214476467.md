# Declaração de Retificação n.º 448/2023 — Retifica o Aviso n.º 7071/2023, publicado no Diário da República, 2.ª série, n.º 68, de 5 de abril de 2023

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Autorização de condução de veículos do Município pela trabalhadora Beatriz Garcia

Para os devidos efeitos se torna público que o [Aviso n.º 7071/2023](https://diariodarepublica.pt/dr/detalhe/aviso/7071-2023-211443219), publicado no Diário da República, 2.ª série, n.º 68, de 5 de abril de 2023, foi publicado com inexatidão, que assim se retifica:

Onde se lê:

«Beatriz Maria Ventura Garcia»

deve ler-se:

«Beatriz Maria Ventura Gouveia»

25 de maio de 2023. - O Presidente do Município, Pedro Miguel César Ribeiro.
