# Declaração de Retificação n.º 742/2023 — Retifica o Aviso n.º 11937/2023, de 23 de junho, publicado no Diário da República, 2.ª série, n.º 121, de 23 de junho…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
