# Declaração de Retificação n.º 702/2023 — Retifica o Despacho (extrato) n.º 7417/2023, publicado no Diário da República, 2.ª série, n.º 136, de 14 de julho de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Ao abrigo do disposto nos n.os 2 e 3 do artigo 11.º do Regulamento de Publicação de Atos no Diário da República, aprovado pelo [Despacho Normativo n.º 16/2022](https://diariodarepublica.pt/dr/detalhe/despacho-normativo/16-2022-205457496), de 30 de dezembro, declara-se que o [Despacho (extrato) n.º 7417/2023](https://diariodarepublica.pt/dr/detalhe/despacho-extrato/7417-2023-215646995), publicado no Diário da República, 2.ª série, n.º 136, de 14 de julho de 2023, saiu com a seguinte inexatidão, que assim se retifica:

Onde se lê:

«Unidade de Ação Fiscal

|  |  |  |  |
| --- | --- | --- | --- |
| Posto | Número de matrícula | Nome | Nome |
| Guarda-Principal ... | 2010430 | Manuel Casimiro de Barros Teixeira. | » |

deve ler-se:

«Comando Territorial de Lisboa

|  |  |  |  |
| --- | --- | --- | --- |
| Posto | Número de matrícula | Nome | Nome |
| Cabo ... | 2010430 | Nuno Joel Agostinho Martins | » |

4 de setembro de 2023. - O Diretor de Justiça e Disciplina, Manuel Augusto Silva Caldeira, Coronel.
