# Declaração de Retificação n.º 585/2023 — Retifica o Despacho (extrato) n.º 6571/2023, publicado no Diário da República, 2.ª série, n.º 117, de 19 de junho de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
