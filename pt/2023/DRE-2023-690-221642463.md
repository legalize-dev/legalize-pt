# Declaração de Retificação n.º 690/2023 — Retifica o Aviso (extrato) n.º 14095/2023, publicado no Diário da República, 2.ª série, n.º 143, de 25 de julho de 2023

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter sido publicado com inexatidão o [Aviso (extrato) n.º 14095/2023](https://diariodarepublica.pt/dr/detalhe/aviso-extrato/14095-2023-216140778) no Diário da República, 2.ª série, n.º 143, de 25 de julho de 2023, a p. 43, retifica-se o mesmo.

Assim:

Onde se lê:

«[...]

|  |  |  |  |
| --- | --- | --- | --- |
| Nome | Cargo/carreira | Nível remuneratório | Data de efeito |
| [...] | [...] | [...] | [...] |
| Sónia Cristina do Nascimento Ferreira... | Assistente técnica... | 7 | 01-02-2023 |

[...]»

deve ler-se:

«[...]

|  |  |  |  |
| --- | --- | --- | --- |
| Nome | Cargo/carreira | Nível remuneratório | Data de efeito |
| [...] | [...] | [...] | [...] |
| Sónia Cristina do Nascimento Ferreira... | Assistente técnica... | 8 | 01-02-2023 |

[...]»

31 de agosto de 2023. - A Presidente, em exercício, Fernanda Rodrigues.
