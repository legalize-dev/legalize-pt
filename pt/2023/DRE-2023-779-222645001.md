# Declaração de Retificação n.º 779/2023 — Retifica o Aviso n.º 18300/2023, publicado no Diário da República, 2.ª série, n.º 184, de 21 de setembro de 2023

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Abertura de vários procedimentos concursais por tempo indeterminado

Para os devidos efeitos se torna público que o Aviso n.º 18300/2023, inserido no Diário da República, 2.ª série, n.º 184, de 21 de setembro de 2023, foi publicado com inexatidão, que assim se retifica:

Onde se lê:

«[...] deverão ainda os candidatos ser detentores de carta de condução de categoria B [...]»

deve ler-se:

«[...] deverão ainda os candidatos ser detentores de carta de condução de categoria C [...]»

28 de setembro de 2023. - O Presidente da Câmara, Marcelo David Coelho Guerreiro.
