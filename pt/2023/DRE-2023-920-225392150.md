# Declaração de Retificação n.º 920/2023 — Retifica o Aviso (extrato) n.º 12781/2023, publicado no Diário da República, 2.ª série, n.º 128, de 4 de julho de 2023

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
