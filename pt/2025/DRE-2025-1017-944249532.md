# Declaração de Retificação n.º 1017/2025/2 — Retifica o Despacho n.º 12610/2025, publicado no Diário da República, 2.ª série, n.º 208, de 28 de outubro de 2025

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
