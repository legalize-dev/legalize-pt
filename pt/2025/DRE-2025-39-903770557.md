# Declaração de Retificação n.º 39/2025/2 — Retifica o anexo ao Aviso n.º 24345-E/2024/2, publicado no Diário da República, 2.ª série, n.º 212, suplemento, de 31…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Tendo-se verificado que o anexo ao [Aviso n.º 24345-E/2024/2](https://diariodarepublica.pt/dr/detalhe/aviso/24345-e-2024-895356921), publicado no Diário da República, 2.ª série, n.º 212, suplemento, de 31 de outubro de 2024, referente ao mapa de vagas para ingresso na formação geral, no âmbito do procedimento concursal para ingresso no internato médico 2025, saiu com inexatidão face ao texto original, importa proceder à sua retificação.

Assim, onde se lê:

| Instituição de colocação | Número de vagas |
| --- | --- |
| [...] | [...] |
| LVT | Total 725 |
| ULS de São José, E. P. E. | 124 |
| ULS do Médio Tejo, E. P. E. | 28 |
| [...] |  |
| Total Geral | 2199 |

deve ler-se:

| Instituição de colocação | Número de vagas |
| --- | --- |
| [...] |  |
| LVT | Total 725 |
| ULS de São José, E. P. E. | 125 |
| ULS do Médio Tejo, E. P. E. | 27 |
| [...] |  |
| Total Geral | 2199 |

9 de janeiro de 2025. - A Vogal do Conselho Diretivo, Paula Cabral Oliveira.
