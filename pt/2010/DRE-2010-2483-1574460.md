# Declaração de Rectificação n.º 2483/2010 — Aviso n.º 23763/2010, de 17 de Novembro

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Por ter saído com inexactidão o aviso n.º 23763/2010 no Diário da República, 2.ª série, n.º 223, de 17 de Novembro de 2010, rectifica-se, assim, o n.º 8.3, onde se lê «CF = AC x 0,60 % + EAC x 0,40 %» deve ler-se «CF = AC x 60 % + EAC x 40 %».

18 de Novembro de 2010. - A Presidente da Câmara, Berta Ferreira Milheiro Nunes.
