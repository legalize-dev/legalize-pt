# Declaração de Rectificação n.º 1355/2010 — Rectifica a lista unitária de ordenação final dos candidatos aprovados após homologação

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Para os devidos efeitos se rectifica o aviso desta Câmara Municipal n.º 12 721/2010, publicado no Diário da República, 2.ª série, n.º 121, de 24 de Junho de 2010, no título onde se lê «Lista unitária de ordenação final dos candidatos aprovados - Procedimento concursal comum para preenchimento de um posto de trabalho de assistente operacional - [Aviso n.º 12989/2009](https://diariodarepublica.pt/dr/detalhe/aviso/12989-2009-2543071), referência Q» deve ler-se «Lista unitária de ordenação final dos candidatos aprovados - Procedimento concursal comum para preenchimento de dois postos de trabalho de assistente operacional - [Aviso n.º 12989/2009](https://diariodarepublica.pt/dr/detalhe/aviso/12989-2009-2543071), referência Q».

2 de Julho de 2010. - O Presidente da Câmara, Augusto Manuel Neto Carapinha Pólvora.
