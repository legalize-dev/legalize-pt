> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1577/2010

Para os devidos efeitos se rectifica o aviso n.º 10870/2010, publicado no Diário da República, 2.ª série, n.º 105, de 31 de Maio de 2010. Assim, onde se lê «Candidatos aprovados: Rosa Maria Santana Mourão» deve ler-se «Maria Rosa Santana Mourão das Dores».

8 de Julho de 2010. - O Presidente, Manuel Joaquim dos Santos Canilhas.
