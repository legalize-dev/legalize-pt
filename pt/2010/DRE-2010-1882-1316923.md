# Declaração de Rectificação n.º 1882/2010 — Rectifica o aviso n.º 17 740/2010

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1882/2010

Por ter saído com inexactidão o aviso n.º 17 740/2010, publicado no Diário da República, 2.ª série, n.º 175, de 8 de Setembro de 2010, rectifica-se que onde se lê «Procedimento concursal comum de recrutamento, para ocupação de 7 postos de trabalho» deve ler-se «Procedimento concursal comum de recrutamento para ocupação de quatro postos de trabalho».

8 de Setembro de 2010. - A Directora, Ana Alzira Pereira.
