# Declaração de Rectificação n.º 1592/2010 — Rectifica o aviso n.º 15266/2010 - projecto de lista de classificação final referente ao concurso para enfermeiros

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1592/2010

Por ter sido publicado com inexactidão o aviso n.º 15266/2010, publicado no Diário da República, 2.ª série, n.º 148, de 2 de Agosto de 2010, rectifica-se que onde se lê «Liliana Teresa Aguieiras Marques - ,80» deve ler-se «Liliana Teresa Aguieiras Marques - 17,80».

3 de Agosto de 2010. - O Presidente do Conselho de Administração, José Manuel Gonçalves André.
