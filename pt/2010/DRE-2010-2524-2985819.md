# Declaração de Rectificação n.º 2524/2010 — Rectifica o aviso n.º 23855/2010, publicado no Diário da República, 2.ª série, n.º 224, de 18 de Novembro de 2010

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2524/2010

Para os devidos efeitos se declara que o aviso n.º 23855/2010, publicado no Diário da República, 2.ª série, n.º 224, de 18 de Novembro de 2010, saiu com inexactidão, que assim se rectifica, onde se lê «Carla Maria Santos Seco Esteves» deve ler-se «Carla Maria Coelho dos Santos Saco Esteves».

18 de Novembro de 2010. - A Secretária-Geral, Nelza Vargas Florêncio.
