# Declaração de Rectificação n.º 1949/2010 — Rectificação do despacho (extracto) n.º 14294/2010, de 7 de Setembro, publicado no Diário da República, 2.ª série, n.º…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 1949/2010

Para os devidos efeitos, declara-se que o despacho (extracto) n.º 14294/2010, de 7 de Setembro, publicado no Diário da República, 2.ª série, n.º 179, de 14 de Setembro de 2010, saiu com a seguinte inexactidão que agora se rectifica. Onde se lê «efeitos a partir de 26-08-2010» deve ler-se «efeitos a partir de 16-08-2010».

14 de Setembro de 2010. - O Director Regional, Rui Salgueiro Ramos Moreira.
