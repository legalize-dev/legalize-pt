# Declaração de Rectificação n.º 2534/2010 — Para os devidos efeitos, rectifica-se o aviso n.º 23 973/2010, publicado no Diário da República, 2.ª série, n.º 224, de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2534/2010

Para os devidos efeitos, rectifica-se o aviso n.º 23 973/2010, publicado no Diário da República, 2.ª série, n.º 224, de 18 de Novembro de 2010. Assim, onde se lê «Vítor Manuel Colaço Costa Chaves» deve ler-se «Vítor Manuel Colaço Costa».

23 de Novembro de 2010. - O Director Municipal, Rui M. Pereira.
