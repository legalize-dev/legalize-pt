# Declaração de Rectificação n.º 2355/2010 — Rectificação ao aviso n.º 21274/2010

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Declaração de rectificação n.º 2355/2010

Para os devidos efeitos se torna público que, por ter sido publicado com inexactidão o aviso n.º 21274/2010, publicado no Diário da República, 2.ª série, n.º 206, de 22 de Outubro de 2010, rectifica-se que no n.º 23 onde se lê «Ref. G [...] António Manuel Sequeira Bento» deve ler-se «Referência C [...] António José Bento Sequeira».

26 de Outubro de 2010. - A Presidente da Câmara, Maria Isabel Fernandes da Silva Soares.
