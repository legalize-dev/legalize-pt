# Declaração de Retificação n.º 26/2017 — Declaração de retificação à Lei n.º 64/2017, de 7 de agosto, que «Estabelece as prescrições mínimas em matéria de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**
