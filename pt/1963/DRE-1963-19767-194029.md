# Portaria n.º 19767 — Manda abonar ao Consulado de Portugal em Windhoek, com efeitos a partir de 1 de Abril próximo, várias quantias a fim de…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Contínuo ... 13-00-00

... 138-00-00
