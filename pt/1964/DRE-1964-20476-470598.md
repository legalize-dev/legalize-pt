# Portaria n.º 20476 — Manda abonar ao Consulado de Portugal em Lião, com efeitos a partir de 1 de Março corrente, várias quantias mensais a…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Chanceler ... 1150,00

Empregado ... 700,00

... 3850,00

Ministério dos Negócios Estrangeiros, 26 de Março de 1964. - O Ministro dos Negócios Estrangeiros, Alberto Marciano Gorjão Franco Nogueira.
