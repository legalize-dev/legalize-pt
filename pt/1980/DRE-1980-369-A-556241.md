# Despacho Normativo n.º 369-A/80 — Mantém todas as delegações conferidas pelo Primeiro-Ministro, Dr. Francisco Sá Carneiro, bem como as autorizações para…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Mantenho todas as delegações conferidas pelo Primeiro-Ministro, Dr. Francisco Sá Carneiro, bem como as autorizações para subdelegar as competências delegadas.

Presidência do Conselho de Ministros, 5 de Dezembro de 1980. - O Vice-Primeiro-Ministro, Diogo Pinto de Freitas do Amaral.
