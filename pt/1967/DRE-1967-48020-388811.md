# Decreto-Lei n.º 48020 — Regulariza a sistema adoptado para o processamento das guias relativas à cobrança das importâncias a que se refere o…

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

Tornando-se necessário regularizar o sistema adoptado para o processamento das guias relativas à cobrança das importâncias a que se refere o [Decreto-Lei n.º 36874](https://diariodarepublica.pt/dr/detalhe/decreto-lei/36874-1948-388629), de 17 de Maio de 1948;

Usando da faculdade conferida pela 1.ª parte do n.º 2.º do artigo 109.º da Constituição, o Governo decreta e eu promulgo, para valer como lei, o seguinte:

###### Artigo único. Enquanto não se proceder à reorganização da Comissão dos Explosivos, as guias a que se refere o artigo 2.º do [Decreto-Lei n.º 36874](https://diariodarepublica.pt/dr/detalhe/decreto-lei/36874-1948-388629), de 17 de Maio de 1948, poderão ser processadas pelas entidades que devam satisfazer as importâncias previstas naquele diploma.

**Publique-se e cumpra-se como nele se contém.**
